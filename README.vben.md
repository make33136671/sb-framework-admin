# SBAdmin - Enterprise Management Frontend

Enterprise-grade admin dashboard built on Vue 3 + TypeScript + Vite, based on Vben Admin v5.5.9.

## Quick Start

**Requirements**: Node.js >=20.12.0, pnpm >=10.0.0

```bash
pnpm install
pnpm run dev:antd        # http://localhost:5173
```

See [docs/README.md](./docs/README.md) for complete guide.

## Build Commands

```bash
pnpm build           # Build all apps
pnpm build:antd      # Build Ant Design version
pnpm lint            # Run ESLint
pnpm format          # Format code
```

## Tech Stack

- **Framework**: Vue 3.5.24 + TypeScript 5.9.3
- **Build Tool**: Vite (latest)
- **UI Library**: Ant Design Vue 4.2.6
- **State**: Pinia 3.0.4
- **Router**: Vue Router 4.6.3
- **Package Manager**: pnpm >=10.0.0

## Browser Support

Modern browsers (Chrome 80+, Firefox, Safari, Edge)
