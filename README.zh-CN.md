# SBAdmin - 企业级管理后台

基于 Vue 3 + TypeScript + Vite，采用 Vben Admin v5.5.9 的企业级管理后台前端。

## 快速开始

**环境要求**：Node.js >=20.12.0，pnpm >=10.0.0

```bash
pnpm install
pnpm run dev:antd        # http://localhost:5173
```

完整指南请查看 [docs/README.md](./docs/README.md)。

## 构建命令

```bash
pnpm build           # 构建所有应用
pnpm build:antd      # 构建 Ant Design 版本
pnpm lint            # 运行 ESLint
pnpm format          # 格式化代码
```

## 技术栈

- **框架**：Vue 3.5.24 + TypeScript 5.9.3
- **构建**：Vite (最新版)
- **UI 库**：Ant Design Vue 4.2.6
- **状态管理**：Pinia 3.0.4
- **路由**：Vue Router 4.6.3
- **包管理器**：pnpm >=10.0.0

## 浏览器支持

现代浏览器（Chrome 80+、Firefox、Safari、Edge）
